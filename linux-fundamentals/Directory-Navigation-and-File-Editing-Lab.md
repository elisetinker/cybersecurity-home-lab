# Linux Directory Navigation & File Editing Lab 

## Summary 
Created a linux practice directory, moved around folders, created a notes file, and edited it using nano.

## Commands Learned
### `pwd`
Displays the current directory
### `ls`
Lists files and directories
### `cd`
Moves between directories
### `cd ..`
Moves to the previous directory
### `mkdir`
Creates a directory
### `touch`
Creates a file 
### `cat`
Displays the contents of a file
### `nano`
Allows the user to edit the file
### `rm`
Removes a specified file or directory

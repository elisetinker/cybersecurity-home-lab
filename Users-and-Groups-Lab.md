# Users and Groups Lab

## Summary
Created a new user and group in Linux. Learned how Linux manages accounts and group membership to control access.

## Commands Learned 
### `id`
Displays user ID, group ID, and group membership
### `useradd`
Creates a new user
### `groupadd`
Creates a new group
### `groups`
Displays the groups that a user belongs to
### `usermod`
Modifies a user account, including adding users to groups
### `passwd`
Creates or changes a user's password
### `cat /etc/passwd`
Displays information about user accounts on the system
### `su`
Switches to another user account
### `grep`
Searches for text patterns within files or command output

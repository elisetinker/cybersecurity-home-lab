# Processes and Services Lab

## Summary
Practiced viewing and managing Linux processes and services. Learned how to monitor running programs, identify processes, and terminate processes. A process is something that is currently running and a service is a type of process that is running in the background and provides a specific function.

## Commands Learned
### `ps`
Displays currently running proceesses
### `ps aux`
Shows detailed information about all running processes
### `top`
Provides a real-time view of system processes and resource usage
### `systemctl`
Manages and displays Linux services
### `kill`
Terminates a process using it's process ID
### `sleep 300 &`
Creates a temporary background process to practice viewing and stopping processes

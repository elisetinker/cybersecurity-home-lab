# Networking Commands Lab

## Summary
Practiced using Linux networking commands to view network information, test connectivity, and check active connections.

## Commands Learned
### `hostname`
Displays the system's hostname
### `ip addr`
Displays network interface information and IP addresses
### `ping` 
Tests connectivity between systems
### `ss -tuln`
Displays listening ports and network connections
### `nslookup`
Queries DNS information for a domain
